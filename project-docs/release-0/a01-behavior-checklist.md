# A01 功能回歸驗收表

執行狀態欄先以 `待驗證` 記錄；Release 0 後續每次改版都應在手機、平板與桌面至少各跑一次。

| ID | 行為 | 驗收條件 | 狀態 |
| --- | --- | --- | --- |
| A01-01 | 初次載入 | Logo、slogan、稜量背景、搜尋與工具內容可見；不依賴第三方 CDN 才能顯示主要內容 | 待驗證 |
| A01-02 | 工具清單 | 入口顯示 28 個既有工具，名稱、品牌名、分類與連結與 `baseline-tools.json` 一致 | 待驗證 |
| A01-03 | 關鍵字搜尋 | 可用中文名稱、英文品牌名、功能描述或適合對象找到工具；無結果時有明確 Empty State | 待驗證 |
| A01-04 | 分類篩選 | 全部、探索、研究、策略、風控、配置可切換，結果數量與分類一致 | 待驗證 |
| A01-05 | 我的最愛 | 點擊心形可加入／移除收藏；重新整理後狀態保留；收藏篩選可使用 | 待驗證 |
| A01-06 | 首頁釘選 | 可釘選工具到首頁；最多 4 個；超過上限有提示且不覆蓋既有釘選 | 待驗證 |
| A01-07 | 首頁內容 | 首頁只顯示釘選工具或預設推薦；卡片順序穩定且無重複 | 待驗證 |
| A01-08 | 查看全部 | 點擊「查看全部」可開啟工具庫；背景蒙版、標題、關閉操作與返回焦點正常 | 待驗證 |
| A01-09 | 工具詳情 | 點擊資訊按鈕可展開完整描述、核心功能、適合對象與外部連結；關閉後可回到原位置 | 待驗證 |
| A01-10 | 外部連結 | 外部連結開新分頁並使用 `noopener`／`noreferrer`；原入口頁維持開啟 | 待驗證 |
| A01-11 | 鍵盤操作 | Tab 可到達搜尋、分類、收藏、釘選、資訊與關閉控制；Escape 可關閉面板 | 待驗證 |
| A01-12 | 響應式版面 | 手機不需水平溢出即可操作；平板與桌面分類列可完整觸達；卡片不重疊 | 待驗證 |
| A01-13 | 儲存降級 | localStorage 不可用時，入口仍可搜尋、篩選與開啟工具，不因例外白屏 | 待驗證 |
| A01-14 | 動畫偏好 | `prefers-reduced-motion: reduce` 時不強制播放非必要動畫 | 待驗證 |

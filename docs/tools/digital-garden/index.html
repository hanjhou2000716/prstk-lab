🌱 數園智庫

DigitalGarden

以數位花園串接投資觀點、研究框架與數據筆記，沉澱可持續迭代的個人知識網絡。

核心功能

  • 將投資觀點、研究框架與數據筆記結構化串接成網狀知識網絡。
  • 以極簡模組化數位花園呈現研究內容，支援回顧、驗證與迭代。

適合對象

  • 偏好體系化累積投資框架、重視思維複利的研究型投資人。
  • 想擺脫雜亂筆記、建立專屬結構化市場洞察庫的自主學習者。

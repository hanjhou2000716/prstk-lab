BetaAlign

Beta 監控與配置偏離預警：輸入持股即可快速掌握目前的投資組合 Beta 值，並即時檢視「正二（槓桿 ETF）/ 現金」配置是否偏離目標設定。

核心功能

  • Beta 監控與配置偏離預警：輸入持股即可快速掌握目前的投資組合 Beta 值，並即時檢視「正二（槓桿 ETF）/ 現金」配置是否偏離目標設定。
  • 動態再平衡決策輔助：自動化判斷當天是否需要進行資產再平衡，並精確給出建議買賣的股數與具體金額。

適合對象

  • 想擺脫情緒干擾，追求讓長期投資變得更簡單、更有紀律的資產配置投資人。
  • 專注於正二（槓桿 ETF）與指數化投資，需要自動化工具輔助計算再平衡權重的交易者。

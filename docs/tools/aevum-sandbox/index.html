⏳ 退休沙盒模擬

AevumSandbox

科學動態退休框架（LMP+RP+ABW）：以低風險資產鎖定基本生活費，搭配成長型資產並透過「攤還式提領」隨市場動態調整，確保資金安穩花到最後一天。

核心功能

  • 科學動態退休框架（LMP+RP+ABW）：以低風險資產鎖定基本生活費，搭配成長型資產並透過「攤還式提領」隨市場動態調整，確保資金安穩花到最後一天。
  • 多資產分群生命週期模擬：支援建立多達 20 個自訂群組，將人生各階段的複雜收入、支出與投資拆分管理，合併模擬出完整的年度現金流與資產趨勢。

適合對象

  • 追求精準財務規劃的 FIRE 實踐者：希望告別粗估的 4% 提領率，改用更科學的 LMP+RP 框架配置資產者。
  • 面臨複雜財務情境的雙薪家庭或中產階級：有房貸、子女教育費、多重收入交織，需要進行分段、動態模擬的投資人。
